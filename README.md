# Adele Chase — MLIS Portfolio

A static migration of https://adelechase.wixsite.com/mlis-portfolio, retrieved October 3, 2026. Original wording is preserved. Layout is rebuilt for responsive pages and keyboard navigation. Images and the five Wix-hosted PDFs are stored locally; the LibGuide and Google Drive assignment remain external links.

## Publish

After merging, open Settings → Pages. Choose Deploy from a branch, main, /(root), and Save. The expected URL is https://adelechase.github.io/mlis-portfolio/.

## Preview and edit

Run `python -m http.server 8000` in this folder and visit http://localhost:8000. Edit the corresponding HTML page to update its content; edit style.css to change its appearance.
